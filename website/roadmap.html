ROADMAP

Where the mesh goes next.

Meshtrike is built in the open. This is what already works, what we’re testing now and what comes next, in order. Dates are left out on purpose: a stage ships when it’s ready and tested, not before.

  • Shipped
  • In testing
  • Planned
  • Exploring
Shipped

Shipped so far.

Working in the app today, phone to phone, with no network.

  • Mesh messaging with honest delivery ticks
  • The route pill
  • Groups up to 50 and public channels
  • Photos, files and video previews
  • Swipe to reply
  • QR handoff, camera to camera
  • Long range with Meshtastic LoRa radios
  • Disappearing messages
  • High-Risk mode
  • Duress PIN and panic wipe
  • The MeshGRID add-on: Wi-Fi Direct and the private internet route over the Nym mixnet

THE ROAD AHEAD

Five stages, in order.

Each stage builds on the one before. Follow the line down: the pulsing stop is where we are today.

  1. Now01 / 05
    NOWIn progress · field testing

    Field testing

    Everything in this stage is built and passes 27 end-to-end mesh scenarios in the simulator. What’s left is the real world: many phones in one place, people walking in and out of range, a full day on one battery.

    • Voice notes, about 120 KB a minute
    • Nearby calls over Bluetooth and Wi-Fi Direct
    • Reply quotes, on voice notes too
    • The MeshGRID add-on and its download flow

    On the test bench: 20+ phones in a crowd, calls at the edge of Bluetooth range, the cost of relaying for others over 24 hours.

  2. Next02 / 05
    NEXTPlanned

    The first signed release

    The step that lets anyone, anywhere, check that the copy they were handed is the real one.

    • Release keys, kept offline: one Android signing key, plus OpenPGP and minisign keys for the checksums
    • Signed APKs on GitHub Releases, free, no account, with checksums signed twice
    • Verify anywhere: in the browser on the verify page, or with one command, sh verify.sh
    • Reproducible builds: rebuild the same APK from source and compare it byte for byte
    • F-Droid and IzzyOnDroid, the open-source app stores
  3. Then03 / 05
    NEW
    THENPlannedNew milestone

    Community servers, run by volunteers

    Meshtrike servers run by loyal volunteers, the way people run Tor relays. Meshtrike never needs one to work. When one is around, the mesh reaches further.

    • MailboxHolds sealed messages for phones that are offline, until they come back.
    • Bridge between meshesJoins separate meshes, in other towns or other countries, whenever any phone in them reaches the internet.
    • Disguise bridge, laterWhere the internet route is blocked, helps it look like ordinary web traffic.

    Only ever sees sealed envelopes. No contents. No contact lists. No who-talks-to-whom.

    • Easy to run: one small program or container
    • A public list of servers, signed by the team
    • No single server is ever required
    Want to run one? Tell us on GitHub
  4. Then04 / 05
    THENPlanned

    Offline maps and a security audit

    During a shutdown, ordinary map apps stop working: they need servers to draw the map, search and find a route. Meshtrike’s map will need none of that.

    • GPS
    • Galileo
    • GLONASS
    • BeiDou
    • NavIC
    • Positions straight from satellites. The phone only listens, so working out where you are transmits nothing
    • OpenStreetMap maps stored on the phone, with search that works on the map file itself
    • Maps shared phone to phone, so one prepared phone can equip a whole group
    • Share a place, not a trail. Pins and meeting points travel as sealed messages. Live location is opt-in and time-limited

    Independent security audit. An external review of the core and the app, a formal model of the handshake and envelope format, and a public report. Before that, treat Meshtrike as beta for high-risk use.

  5. Later05 / 05
    LATERExploring

    iPhone app, group calls, disguise bridges

    iPhone app

    • Shared Rust core. Messages, encryption and storage are the same code as on Android
    • Bluetooth limits on iOS. Works fully while the app is open, and carries messages in the background where iOS allows it
    • No Wi-Fi Direct on iPhone. Apple’s own peer-to-peer Wi-Fi between iPhones, Bluetooth between iPhone and Android
    • Same sealed messages, contacts and safety numbers between iPhone and Android

    Group calls

    Calls with several people nearby, over Wi-Fi Direct first, with fresh keys every call.

    Disguise bridges

    Ways for the internet route to look like ordinary web traffic where the Nym mixnet is blocked.
