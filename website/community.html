COMMUNITY

Get involved.

A mesh is only as strong as the people in it. Every phone that carries a message, every bug report and every translation makes Meshtrike work better for someone in a hard place. No sign-ups and no forms: everything happens in the open on GitHub.

Ways to help

  • Coming soon

    Run a community server

    Volunteer servers will hold sealed messages for phones that are offline and bridge separate meshes in other towns and countries, the way volunteers run Tor relays. They only ever see sealed envelopes, and no single one is ever required. It will be one small program or container to run.

    Tell us you’d run one On the roadmap

  • Test it at events

    Use Meshtrike with friends at a festival, a march, on a hike or a boat. Then tell us what broke, how fast messages arrived and what the battery did.

    Report what you found

  • Translate

    Meshtrike should speak the languages of the people who need it most. Open an issue for your language and we’ll work out the details together.

    Offer a language

  • Review the code and the whitepaper

    The design, the specification and every line of code are public. Fresh eyes on the protocol and the threat model are worth more than anything.

    Read the whitepaperBrowse the code

  • Report security issues privately

    Found something that lets a relay read, link or trace messages, or a way to pass off a fake APK? Please report it privately, never in a public issue.

    Report a vulnerability

  • Spread the APK, phone to phone

    One APK works on any number of phones. Pass it on before the network goes down, and show people how to check their copy on the verify page.

    Sharing tipsVerify a copy

GOOD TO KNOW

How we work together.

  • Pseudonyms are welcome. You never need your real name to help. Think about your own safety before you post.
  • Everything is in the open. Ideas, bugs and plans live in GitHub issues where anyone can read them.
  • Security problems are the exception. Those go through private reporting first.
