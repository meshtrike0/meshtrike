01 · HOW TO INSTALL

Four steps, about two minutes.

Meshtrike isn’t in the Google Play Store, so Android asks you to allow the install once. That’s normal for apps from outside Play.

  1. 1

    Download the APK

    Tap Download APK above on your Android phone. On a computer, scan the code to open this page on your phone.

  2. 2

    Open the file

    Open it from your browser’s downloads or your Files app. Want to be sure first? Check it on the verify page.

  3. 3

    Allow installing from this source

    Android asks once: allow your browser or Files app to install unknown apps, then tap Install. On newer Android versions you may also need a one-time “advanced” confirmation, and a short waiting period, before apps from outside Google Play can be installed.

  4. 4

    Open Meshtrike and pair

    Set your PIN, then meet your people and scan each other’s codes in person, so everyone shows as Verified. Add MeshGRID the same way if you want it.

Share it phone to phone

One APK works on any number of phones. Pass it on with Nearby Share, Bluetooth or a USB stick; nobody has to download it from here. Each install makes its own keys. Anyone can check a copy they were handed on the verify page.

Where releases live

Every version is published on GitHub Releases, free and without an account, together with signed checksums and the verify.sh script.
